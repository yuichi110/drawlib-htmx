htmx v4.0.1 内部アーキテクチャガイド

htmx v4.0.1（コードネーム "The Fetchening"）は、htmx 2.x の 4,000 行超におよぶレガシーな XMLHttpRequest クロージャ実装をゼロから再設計したフルスクラッチのリライト版です。fetch()、AbortController、明示的な :inherited 属性解決、独自設定記法 HCON（htmx Configuration Object Notation）、組込みの Idiomorph 型 DOM 差分調整（Morphing）エンジン、および 15 個の内部プリミティブを公開する #internalAPI 拡張ブリッジを備えた、2,373 行の単一 ES2022 Htmx クラス（src/htmx.js）として構築されています。

2. リクエスト・Swap・拡張フックの全体ライフサイクル

htmx v4 におけるすべてのハイパーメディア操作は、トリガーイベント評価（__onTrigger）からリクエストコンテキスト生成（__createRequestContext）、同期キュー制御（RequestQueue.admit）、fetch() 通信（__issueRequest）、マルチタスク断片抽出（swap）、そして DOM 挿入・差分調整（__insertContent / __morph）に至る決定論的な非同期パイプラインを通過します。

4. チャプター構成とナビゲーション

本ガイドは以下の 6 つの詳細チャプターで構成されています：

  1. 第1章 — モジュールと状態管理構造 単一ファイル Htmx クラスの全体構造、package.json における sed __ $\rightarrow$ # プライベートフィールド変換トリック、Constructable CSSStyleSheet 注入、elt._htmx と elt._htmx_state の二層状態ストア、process(root, force)、および #hxOnQuery XPathEvaluator 高速探索。
  2. 第2章 — 属性継承とHCONパーサ HCON 正規表現レキサー、ドット区切りキー展開、HCON.merge のプロトタイプ汚染ガード、data-hx- プレフィックスと metaCharacter 正規化、および __attributeValue による明示的 :inherited / :append 解決アルゴリズム。
  3. 第3章 — トリガーと拡張セレクタ解析 __parseTriggerSpecs トークナイザ、__onTrigger における 3 層イベントリスナ合成（delay, throttle, changed WeakMap, once, IntersectionObserver, every）、および Node.prototype.compareDocumentPosition を用いた __findAllExt 拡張 CSS セレクタエンジン。
  4. 第4章 — Fetchコンテキストと同期キュー __createRequestContext、FormData 収集（__collectFormData & __addInputValues）、RequestQueue 状態機械（hx-sync）、AbortController タイムアウト、htmx:confirm 非同期中断、HX-* ヘッダ処理、および階層型 hx-status:Nxx ルーティング。
  5. 第5章 — Swap・SettleとMorphエンジン __makeFragment における <hx-*> $\rightarrow$ <template hx> 書き換え、[hx-preserve] の Pantry 退避・復元、swap(ctx) のタスク順序（Main $\rightarrow$ OOB $\rightarrow$ <hx-partial>）、組込み Idiomorph 差分調整（__morph, __createIdMaps, morphScanLimit, Node.prototype.moveBefore）、および直列化 View Transitions キュー。
  6. 第6章 — 拡張機構とセキュリティ内部構造 registerExtension と __triggerExtensions によるコロン $\rightarrow$ アンダースコア拡張フックディスパッチ、15 個のプリミティブを公開する #internalAPI ブリッジ、__executeJavaScript と Trusted Types、src/ext/hx-csp.js の 3 層 CSP 防御（hx-nonce, safeEval）、および主要公式拡張（hx-live.js, hx-multipart.js, hx-sse.js, hx-ws.js）の内部実装。
